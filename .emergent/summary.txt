**what currently exists?**
A comprehensive full-stack fleet management application. In addition to the previously existing features (auth, live sheet, admin panels), this session added significant new functionality:
-   **Compliance & Car Management**: Cars now have trackable Tax, NCT, and Service due dates, which trigger red alerts on the admin dashboard. Admins can block cars for appointments, making them unavailable for booking.

-   **Recurring Booking Workflow**: Staff can request recurring bookings, which enter a pending approval state. Admins see these requests on their main dashboard and can approve or reject them. Pending bookings are visually distinguished (greyed out) on the calendar.
-   **Staff Communication**: Admins can create announcements via a Messages tab. These messages are presented to staff in a mandatory, blocking modal upon login, which they must acknowledge to proceed.
-   **UI/UX Improvements**: The application is now fully mobile-responsive, and the logout button is consistently available on all screen sizes.
