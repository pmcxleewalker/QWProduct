# Content Worker Quick Start Guide

## 5-Minute Overview

---

## What is Content Worker?

A complete Instagram content management system for Quick Wing franchises.

**Key Features:**
- Upload and manage media assets
- Create posts with privacy protection
- AI-generated captions
- Schedule and publish to Instagram
- Track performance analytics

---

## Step-by-Step: Create Your First Post

### 1. Access Content Worker
- Login as Super Admin
- Click **Content** tab in Command Centre

### 2. Upload Media
- Go to **Assets** tab
- Click **Upload**
- Select image or video file

### 3. Create Post
- Click **New Post** tab
- Select your uploaded asset
- Follow the 6-step wizard:

| Step | Action |
|------|--------|
| 1. Upload | Select or upload media |
| 2. Frame | Choose video cover (videos only) |
| 3. Privacy | Review & blur sensitive info |
| 4. Preview | Generate branded images |
| 5. Caption | Select AI-generated caption |
| 6. Save | Submit for review |

### 4. Approve Content
- Go to **Review Queue** tab
- Click **eye icon** to preview
- Click **Approve** if ready

### 5. Publish
- Go to **Posted** tab
- Click **Ready to Post** tab
- Either:
  - Set schedule date/time, OR
  - Click **Publish to Instagram**

## Key Actions Reference

| I want to... | Go to... | Click... |
|--------------|----------|----------|
| Upload media | Assets | Upload button |
| Create post | New Post | Start wizard |
| Review content | Review Queue | Eye icon on draft |
| Approve post | Review Queue | Approve button |
| Schedule post | Posted → Ready to Post | Datetime picker |
| Publish now | Posted → Ready to Post | Publish to Instagram |
| Check performance | Analytics | Sync Metrics |
| Get ideas | Ideas | View suggestions |
| Connect Instagram | Settings | Connect Account |

---

## Content Status Flow

```
Draft → In Review → Approved → Scheduled → Posted
            ↓
         Rejected (revise and resubmit)
```

---

## Before You Publish - Checklist

- [ ] Privacy zones reviewed (blur sensitive info)
- [ ] Caption selected
- [ ] Instagram connected (check Settings)
- [ ] Preview looks good
